ProPlan (프로플랜) · 프로의 레슨 · 일정 관리

KPGA 투어 프로가 혼자 자기 레슨을 관리하는 아이폰 앱의 아이디어 검증용 프로토타입입니다.

- 라이브 데모: https://issuelee9040.github.io/Golf--lesson-app/
- 설계서: [spec.md](spec.md)

## 무엇이 들어 있나
- **오늘 · 캘린더 · 회원목록 · 통계 · 설정** 5탭
- 수강권(25분/55분) 잔여 횟수 · 마감 정산 · 수입 정산
- 회원 한 줄 등록 · 골프 전용 레슨 차트 · 카톡 요약 복사 · 재등록 골든타임
- 그린 화이트 / 시크 블랙 두 테마
- **체험판 시작**: 처음 여는 프로는 자기 이름으로 빈 상태에서, 또는 샘플 데이터로 둘러보기로 시작

## 파일
- `index.html` — 프로토타입 (단일 HTML, localStorage 저장)
- `manifest.webmanifest` — 홈화면 앱 이름·아이콘(`ProPlan`)
- `assets/` — ProPlan 로고 락업(테마별)과 홈화면 아이콘(180 · 192 · 512 · 32)
- `spec.md` — 화면·데이터 모델 설계서

## 홈화면에 추가
아이폰 사파리: 공유 → **홈 화면에 추가** → 이름 `ProPlan`, 깃발 아이콘으로 추가됩니다.
안드로이드 크롬: 메뉴 → **홈 화면에 추가**.

모든 데이터는 그 기기의 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다. 샘플은 데모용이며 실제 개인정보가 없습니다.
