ProPlan (프로플랜) · 프로의 레슨 · 일정 관리

KPGA 투어 프로가 혼자 자기 레슨을 관리하는 아이폰 앱의 아이디어 검증용 프로토타입입니다.

- 라이브 데모: https://issuelee9040.github.io/Golf--lesson-app/
- 설계서: [spec.md](spec.md)

## 무엇이 들어 있나
- **오늘 · 캘린더 · 회원목록 · 통계 · 설정** 5탭
- 맨 위 **벡터(인라인 SVG) ProPlan 브랜드 바** · 오늘 카드 **[레슨 차트] → 오늘 레슨 메모** 바로 적기
- 수강권(25분/55분) 잔여 횟수 · 진행 중 횟수(4/10회) 그대로 등록 · 마감 정산 · 수입 정산
- 회원 한 줄 등록(음성 입력 · 횟수는 선택) · **여러 줄 통째로 일괄 등록**(`김민수 4/10회 80만원`) · 골프 전용 레슨 차트 · 카톡 요약 복사 · 재등록 골든타임
- **별도 결제 레슨 3종**: 필드 · 숏게임 · 원포인트 (수강권 미차감, 별도 수입으로 정산)
- **별도 결제로만 온 방문 회원도 회원목록에 보존** — `수강권 없음 · 별도 N회`, 나중에 `+ 수강권 추가`로 전환
- 레슨 상태 5가지는 **절반 높이 2열 타일** (완료 · 당일취소 · 노쇼 · 일반취소 · 보강)
- 그린 화이트 / 시크 블랙 두 테마 — 다크 탭바는 지금 메뉴가 민트 알약으로 또렷하게
- **체험판 시작**: 처음 여는 프로는 자기 이름으로 빈 상태에서, 또는 샘플 데이터로 둘러보기로 시작
- 앱을 열면 **3.5초 실행 스플래시** (탭하면 바로 넘어감)

## 파일
- `index.html` — 프로토타입 (단일 HTML, localStorage 저장)
- `manifest.webmanifest` — 홈화면 앱 이름·아이콘(`ProPlan`)
- `assets/` — ProPlan 로고 락업(테마별) · 홈화면 아이콘(180 · 192 · 512 · 64 · 32, 깃발 위 + ProPlan 아래) · 아이콘 생성기 `_gen.py`
- `spec.md` — 화면·데이터 모델 설계서
- `tests/` — 화면·동작 자동 검사 27종 (수정할 때마다 전부 실행)

## 홈화면에 추가
아이폰 사파리: 공유 → **홈 화면에 추가** → 이름 `ProPlan`, 깃발 + ProPlan 아이콘으로 추가됩니다.
안드로이드 크롬: 메뉴 → **홈 화면에 추가**.

모든 데이터는 그 기기의 브라우저(localStorage)에만 저장되고 서버로 전송되지 않습니다. 샘플은 데모용이며 실제 개인정보가 없습니다.
